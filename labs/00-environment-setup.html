6e. Optional: dirdotenv (terminal lo auto-load)

Bootcamp notes lo ee rendu commands untayi. First di Windows lo work avutundi. Second di Linux/Mac bash ki, Windows lo error vastundi:

10 Lab 03: RAG (Retrieval-Augmented Generation)

Ekkada: notebooks/bootcamp.ipynb (Cell 1 run chesaka)

10a. llm() function (Groq version)

Course notes lo openai_client.responses.create(model="gpt-5.4-mini") undi. Adi OpenAI ki matrame. Groq lo responses API ledu, so chat.completions vadutam:

MODEL = "openai/gpt-oss-120b"

def llm(prompt):
    response = openai_client.chat.completions.create(
        model=MODEL,
        messages=[{"role": "user", "content": prompt}],
    )
    return response.choices[0].message.content

llm("Hey, what's up?")
Expected: "Hey there! I'm doing great..." lanti reply.

10b. Plain LLM test (context lekunda)

question = "I just discovered the course. Can I join now?"
print(llm(question))
Expected: Generic answer ("Enroll Now button click cheyyandi..."). Model ki mana Zoomcamp gurinchi em teliyadu, anduke guess chestundi.

10c. Context manually add chesi test

Notebook lo context (FAQ entries) + prompt (question + context + "I don't know" rule) cells run cheyyandi, tarvata:

print(llm(prompt))
Expected: Yes, you can still join the course. If you'd like to earn a certificate, submit your project before the deadline. ← Correct answer, FAQ nunchi.

10d. RAG skeleton

def rag(question):
    search_results = search(question)          # 1. Retrieval
    user_prompt = build_prompt(question, search_results)  # 2. Prompt
    return llm(user_prompt)                    # 3. Generation
search() and build_prompt() next section (dataset + minsearch) lo vastayi. Ippudu rag() call cheste NameError vastundi, adi expected.
Telugu lo Problem: LLM ki general knowledge undi (salmon ela cook cheyyali), kani mana private data (Zoomcamp FAQ) teliyadu. Direct ga adigite generic, wrong answer istundi. Solution: Question tho paatu relevant FAQ text ni prompt lo pettali. Appudu LLM aa text chadivi correct answer istundi. Ide RAG. RAG = Retrieval + Augmented + Generation. Retrieval ante search (knowledge base lo relevant documents vethakadam). Augmented ante aa documents ni prompt ki add cheyyadam. Generation ante LLM answer rayadam. 10c lo manam context ni chethi tho paste chesam. Asalu RAG lo search automatic ga chestundi. Adi next lab. Key point: LLM ki manam icchina documents matrame kanipistayi. Search wrong document isthe answer kuda wrong. So search quality = answer quality. Flexible: 3 pieces independent. Groq badulu Anthropic kavalante llm() matrame marchali. minsearch badulu Elasticsearch kavalante search() matrame marchali.
